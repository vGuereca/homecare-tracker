# Portfolio Roadmap

## Project

HomeCare Tracker

## Goal

The goal of this roadmap is to continue improving HomeCare Tracker from a capstone project into a stronger recruiter-facing portfolio project.

## Phase 1: GitHub Portfolio Cleanup

Status: In progress

Planned work:

- Move project to public GitHub repository
- Create professional README
- Add project summary
- Add portfolio roadmap
- Add screenshots or GIF demo
- Clean WGU-specific references from the main recruiter-facing view

## Phase 2: Authentication and User Accounts

Planned work:

- Add user registration
- Add user login
- Hash passwords with BCrypt
- Add JWT authentication
- Protect backend endpoints
- Protect frontend routes
- Add logout functionality

## Phase 3: User-Specific Data

Planned work:

- Add user entity
- Add relationship between users and maintenance tasks
- Ensure users only see their own tasks
- Add tests proving user data isolation

## Phase 4: UI and UX Improvements

Planned work:

- Add polished landing page
- Add navigation bar or sidebar
- Improve dashboard cards
- Improve task form layout
- Improve validation messages
- Add empty states
- Add loading states
- Improve mobile responsiveness

## Phase 5: Recurring Maintenance Tasks

Planned work:

- Add recurring task options
- Add repeat intervals
- Calculate next due date
- Generate next task when recurring task is completed
- Add recurring task tests

## Phase 6: AI-Assisted Maintenance Planning

Planned work:

- Add AI maintenance task suggestion feature
- Allow users to enter home details
- Generate recommended maintenance tasks
- Allow users to save selected AI suggestions
- Add AI-generated seasonal maintenance checklist

## Phase 7: Reports and Analytics

Planned work:

- Add cost by category chart
- Add overdue task report
- Add upcoming 30-day task report
- Add completed task history
- Add monthly estimated cost chart

## Phase 8: File and Photo Attachments

Planned work:

- Add receipt uploads
- Add repair photo uploads
- Attach files to maintenance tasks
- Explore AWS S3 for cloud file storage

## Phase 9: Notifications and Reminders

Planned work:

- Add in-app reminders
- Add upcoming due date alerts
- Add overdue task alerts
- Explore email reminders

## Phase 10: CI/CD and Deployment Polish

Planned work:

- Add GitHub Actions for backend tests
- Add GitHub Actions for frontend build
- Add Docker build validation
- Add HTTPS
- Add custom domain
- Improve production deployment documentation

## Priority Order

Recommended next steps:

1. Finish GitHub portfolio cleanup

4. Improve UI/UX
5. Add recurring tasks
6. Add AI-assisted task suggestions
