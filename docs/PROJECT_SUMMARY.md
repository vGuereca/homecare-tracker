# Project Summary

## Project Name

HomeCare Tracker

## Original Project Name

Home Maintenance Tracker and Cost Prioritization Application

## Purpose

HomeCare Tracker is a full-stack web application designed to help homeowners track maintenance tasks, due dates, estimated costs, urgency levels, and completion status.

The project started as a software engineering capstone and is being improved as a public portfolio project.

## Problem Solved

Homeowners often manage repairs and maintenance informally through memory, notes, or scattered receipts. This can lead to missed maintenance, unexpected costs, and poor prioritization.

HomeCare Tracker provides a centralized system for organizing maintenance work and understanding which tasks need attention first.

## Current Capabilities

The current version supports:

- Task creation
- Task viewing
- Task editing
- Task completion
- Task deletion
- Task search
- Task filtering
- Task sorting
- Dashboard summaries
- Maintenance reports
- Cloud deployment
- Dockerized runtime

## Technical Highlights

The project demonstrates:

- React frontend development
- Java Spring Boot backend development
- REST API design
- PostgreSQL database persistence
- JPA entity modeling
- Service-layer business logic
- Backend validation
- Automated backend testing
- Dockerfiles for frontend and backend

The next major upgrade is authentication.

Planned authentication features include:

- User registration
- User login

- JWT-based authentication
- Protected frontend routes
- User-specific task ownership

The long-term version of HomeCare Tracker will become a more realistic home management product with:

- Multi-user accounts
- Recurring maintenance schedules
- AI-generated maintenance suggestions
- Cost and urgency recommendations
- Home profile setup
- File and photo attachments
- Email or in-app reminders
- Analytics and charts
- CI/CD pipeline
- HTTPS deployment
