# Setup and Maintenance Guide

## Project Name

Home Maintenance Tracker and Cost Prioritization Application

## Project Purpose

The Home Maintenance Tracker and Cost Prioritization Application is a full-stack web application created for the WGU D424 Software Engineering Capstone. The application allows a user to create, view, update, complete, delete, search, filter, sort, and report on home maintenance tasks.

## Technology Stack

- Frontend: React with Vite
- Backend: Java Spring Boot
- Database: H2 for local development, PostgreSQL for Docker runtime
- API Style: REST
- Testing: JUnit, MockMvc, manual full-stack browser testing
- Containerization: Docker and Docker Compose
- Version Control: GitLab
